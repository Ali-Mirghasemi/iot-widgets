# Changelog

## 0.4.0

- Added production-facing `IoTWidget` public component.
- Added per-widget theme selection independent of showcase global theme.
- Added runtime `data` and `metadata` props.
- Added per-instance `themeOverrides`.
- Added catalog lookup helpers and public runtime types.
- Added optional info and low-level interaction callbacks.
- Made theme visual dispatcher thin and explicit.
- Made info actions optional in reusable frames.
- Added ESM library build + TypeScript declarations.
- Converted React/MUI/Emotion to package peer dependencies.
- Added comprehensive integration, architecture, data, theme, QA and publishing documentation.
- Fixed TypeScript build issues in Material manual-value rendering and Node config.

## 0.3.0

- Multi-theme showcase architecture with dedicated visual directions.
- Adaptive widget size behavior.
